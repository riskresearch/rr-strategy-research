Performance Attribution — S&P500 Core Relative Allocation (SCRA)

S&P 500 Core Relative Allocation (SCRA) is a systematic futures program built around a permanent U.S. large-cap equity core, with dynamic tilts into a diversified set of liquid markets — equities, rates, real assets, and digital assets — when they outperform the core on a risk-adjusted basis. It is always net long equity and aims to compound at an equity-like return while holding realized risk within a controlled band.
