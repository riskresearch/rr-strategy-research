# Core One Research

Independent quantitative research initiative: systematic, volatility-managed equity programs.

Site: https://riskresearch.github.io/rr-strategy-research/

| Path | Content |
|---|---|
| `/` | Landing page (`docs/index.html`, hand-written) |
| `/programs/` | Strategy documents (`strategy/*.qmd` → Quarto) and nightly performance pages (generated on the trading server) |

| `/papers/` | Bilingual paper collection |
| `/data/` | JSON feeds for the landing page (forward test, relative backtests) |
| `/disclosures.html` | Important information |

Legacy URLs under `/strategy/`, `/collection/` and the old root chapter pages are redirect stubs.

Content is for information only and is not an offer, a solicitation or investment advice.
